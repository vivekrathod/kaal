# Kaal instructions for Claude Code

Read and follow [`AGENTS.md`](AGENTS.md) before operating Kaal or its vault.

Use `$HOME/.local/bin/kaal` explicitly if `kaal` is not on `PATH`. Never print
vault bodies, OCR text, tax data, medical data, attachment names, or Keychain
material unless the user explicitly requests that disclosure. Medical receipts
must use `kaal medical …`, not generic note commands.
