Connect to Kaal

The extension sends what you save straight to your Kaal server. It needs the server's address and a device token of its own.

Create one on the server with kaal-server token create chrome-extension --scopes read,reveal,write. It is kept in this browser profile only. Leave this empty to keep the token already saved.

  • The main button saves the page in front of you. On a site you have saved receipts from before, it saves a receipt.
  • A receipt opens beside the page so you can check it straight away.
  • Shortcuts can be changed at chrome://extensions/shortcuts.
